# Instalación

Esta carpeta contiene la guía resumida del despliegue final.

Contenido:

- `Pasos.md`: documento con el orden recomendado para crear las máquinas, preparar `jumpstart`, desplegar los servicios y comprobar el resultado.
- `Archivos/`: scripts principales numerados por fases para ejecutar el despliegue.

Se debe usar como referencia rápida para realizar la instalación completa del entorno WordPress, Galera, balanceador y Zabbix.
