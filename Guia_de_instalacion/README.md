# Guia_de_instalacion

Esta carpeta contiene la guía final preparada para la entrega del proyecto.

Su objetivo es reunir una versión ordenada del proceso de despliegue, con los pasos principales y los archivos necesarios para ejecutar la instalación de forma guiada.

Contenido:

- `Instalacion/`: guía resumida por fases y scripts principales del despliegue.
- `Scripts/`: scripts, playbooks e inventario usados durante la instalación.

La carpeta está pensada como punto de entrada para seguir el despliegue completo sin tener que buscar los archivos en distintas partes del repositorio.
