# docs

Esta carpeta contiene documentación general de apoyo para entender el diseño del proyecto.

Contenido:

- `datos_entrada.md`: datos necesarios para configurar el despliegue, incluyendo redes, IPs, puertos NAT, MACs y credenciales.
- `arquitectura.md`: arquitectura de red, rutas y diagrama de conexiones entre nodos.
- `manual_administracion.md`: operaciones de despliegue, monitorización, ampliación y sustitución de nodos.
- `software_baseline.md`: software utilizado, versiones objetivo, URLs de origen y comandos para obtener versiones reales.

Se utiliza como documentación complementaria a las guías de instalación y a los scripts de automatización.
