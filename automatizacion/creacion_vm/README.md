# creacion_vm

Esta carpeta contiene los scripts para crear las máquinas virtuales del laboratorio en VirtualBox.

Scripts incluidos:

- `crear_jumpstart.sh`
- `crear_router_linux.sh`
- `crear_balanceador.sh`
- `crear_frontend1.sh`
- `crear_frontend2.sh`
- `crear_backend1.sh`
- `crear_backend2.sh`

Cada script se encarga de crear o clonar una máquina concreta y aplicar la configuración inicial necesaria para el despliegue.
