# base_de_datos

Esta carpeta contiene playbooks centrados en la preparación y despliegue de la capa de base de datos.

Contenido:

- `preparar_jumpstart.yml`: prepara la máquina de administración para trabajar con Ansible y los nodos backend.
- `backend.yml`: configura los backends y despliega MariaDB Galera.

Se conserva como bloque específico para las tareas relacionadas con la base de datos y la preparación previa del entorno.
