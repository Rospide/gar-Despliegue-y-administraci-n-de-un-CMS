# scripts

Esta carpeta contiene scripts de Bash usados para preparar las máquinas y lanzar partes del despliegue.

Contenido:

- `configurar_router_linux.sh`: configuración de red y encaminamiento del router Linux.
- `configurar_jumpstart.sh`: preparación inicial de la máquina `jumpstart`.
- `configurar_frontend.sh`: configuración base de los frontends.
- `configurar_backend_red.sh`: configuración de red de los backends.
- `configurar_balanceador.sh`: configuración del balanceador.
- `preparar_ansible.sh`: instalación y preparación de Ansible.
- `desplegar_galera.sh`: despliegue o preparación de Galera en los backends.

Los scripts están pensados para ejecutarse en la máquina correspondiente siguiendo las guías de instalación.
